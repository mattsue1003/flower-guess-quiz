    給帶領者的活動說明

    怎麼帶（30–45 分鐘）

    1. 用投影或大電視開啟本頁，選玩法：長輩建議「看照片猜」，小朋友可以玩「模糊照片」或「局部特寫」（每開一個提示，照片就更清楚、看得更多）。
    2. 先不給提示，請大家說說看「它是什麼顏色、在哪裡看過、聞起來怎樣」。
    3. 猜不到就按提示：顏色和花瓣 → 什麼時候開 → 在哪裡看到 → 香味或用途 → 節慶或俗語 → 名字字數。卡住時按「給三個選項」。
    4. 揭曉後，挑 1–2 個小知識講，再用「聊一聊」的題目讓大家分享回憶。
    5. 最後看一小段影片，或用 Google 圖片看看更多顏色。

    帶領小撇步

    1. 一次玩 6–8 朵就夠，留時間聊天比答對更重要；可以用「季節」只挑當季的花。
    2. 長輩常說小名（桐花、喇叭花、蓮花、太陽花），說出小名也算答對。
    3. 失智症長輩可直接按「給三個選項」，降低挫折感。
    4. 搭配真花或乾燥花：桂花、茉莉、玉蘭、薰衣草可以帶來聞一聞，做五感刺激。
    5. 有毒的花（杜鵑、繡球、油桐果實、牽牛種子）頁面上都有提醒，戶外活動時記得叮嚀。
    6. 影片在 GitHub 網頁版可以直接播放；其他地方會連到 YouTube。
